# M1 规格：应用外壳

覆盖功能：F-APP-001 ~ F-APP-007、F-APP-009、F-APP-010、F-APP-017（应用日志）、F-APP-018、F-APP-019、F-PREF-001、F-PREF-002、F-PREF-010、F-NAV-001（到数据库层级）、F-NAV-003（搜索）、F-NAV-006（连接与组的右键菜单）、F-NAV-008。

行为来源：`main_window.html`、`navigation_pane.html`、`object_pane.html`、`information_pane.html`、`hot_keys.html`、`preferences_gen.html`。尺寸来源见 [02-design-tokens.md](02-design-tokens.md)。

## 1. 启动流程

外壳 `navidog` 的 `main` 依次执行：

1. 初始化 `tracing`，日志写入 `~/Library/Logs/navidog/navidog.log`，按天滚动。
2. 调用 `rust_i18n::extend!(gpui_component)`，从偏好设置中读取语言（默认跟随系统，`zh-*` 用简体中文，其余用英文）。
3. `application().with_assets(NavidogAssets)`，其中 `NavidogAssets` 先查找 navidog 自有的图标，找不到再回退 gpui-kit 的 `Assets`。
4. 在 `run` 回调中依次执行：
   1. `gpui_kit::init(cx)`；
   2. `cx.set_app_identity(...)`，Bundle ID 为 `ci.nn.navidog`；
   3. 加载 Navicat 主题，`font_size` 设为 13，外观跟随系统或使用偏好设置中固定的外观；
   4. 初始化各 crate：`navidog_core::init`、`navidog_db::init`（启动 tokio 运行时）、`navidog_connection::init`；
   5. 先 `cx.bind_keys(...)`，再 `cx.set_menus(...)`；
   6. 打开主窗口。
5. 主窗口打开后，自动打开设置了“自动连接”的连接（F-CONN-012）。

## 2. 主窗口

```
┌──────────────────────────────────────────────────────────────┐
│ ● ● ●                      navidog                          │ 标题栏（红绿灯 + 居中标题）
│ [连接▾] [新建查询] │ [表] [视图] [函数] [用户] [其它▾] [查询] ... │ 主工具栏（Expanded）
├────────────┬───────────────────────────────────┬─────────────┤
│ 导航窗格   │ [对象] [tab2] [tab3]               │ 信息窗格    │
│ 240        │ 对象窗格 734                        │ 264         │
│ (筛选栏)   │                                   │             │
├────────────┴───────────────────────────────────┴─────────────┤
│ 状态栏 24                                                    │
└──────────────────────────────────────────────────────────────┘
```

- 窗口选项来自 `TitleBar::window_options()`，并设置 `app_owns_titlebar_drag: true`。默认内容尺寸为 `window.default_size`（1240 × 800），最小尺寸 800 × 500（暂定，待 AX）。
- 标题栏：macOS 原生红绿灯，标题居中显示“navidog”。标题栏和主工具栏共用 `color.window_bg` 背景，两者之间没有分隔线；工具栏下方有一条 `color.separator` 分隔线。
- 窗口位置和尺寸在关闭时用 `window.window_bounds()` 读取，写入 `state.json`；下次启动时作为 `WindowOptions.window_bounds` 恢复。
- 关闭主窗口时，如果有未保存的编辑器选项卡，逐个询问是否保存。退出应用（⌘Q）同样处理。

## 3. 主工具栏（F-APP-002）

- 按钮为“大图标加文字”：图标 `toolbar.item_icon`，文字使用 `font.size.small`，文字在图标下方；按钮之间的间距为 `toolbar.item_gap`。
- 按钮及其行为：

| 按钮 | 行为 | 适用 | M1 |
| --- | --- | --- | --- |
| 连接 ▾ | 点击打开新建连接的类型选择；下拉列出数据库类型，选中后直接进入对应表单 | 全部 | 实现 |
| 新建查询 | 在当前连接的当前数据库中新建查询（⌘Y） | 选中了已打开的连接时启用 | 禁用，M3 实现 |
| 表、视图、函数、用户 | 把对象选项卡切换到对应分类 | 选中了已打开的连接时启用 | 禁用，M2 实现 |
| 其它 ▾ | 下拉列出其余对象分类：事件 [My]、实体化视图 [PG]、索引和触发器 [Lite] 等 | 同上 | 禁用，M2 实现 |
| 查询、备份、自动运行、模型、BI | 切换到对应分类或工作区 | 同上 | 禁用，在对应里程碑实现 |

- 未实现的按钮显示为禁用状态，而不是隐藏，以保持布局与基线一致。实际按钮集合和顺序要在 AX 实测后核对。
- 每个按钮对应一个 Action，与菜单项共用（例如“连接”对应 `NewConnection`）。
- “查看 > 显示工具栏”（⌥⌘T）切换工具栏的显示，状态持久化。
- 实现：使用 `gpui-component` 的 `Toolbar`；按钮外观由 `navidog-ui` 的 `ToolbarItem` 皮肤提供，因为 `Toolbar` 默认的 Small 尺寸不支持“图标在上、文字在下”。

## 4. Dock 布局（F-APP-001、F-APP-006、F-APP-007）

- 使用 `gpui-component` 的 `DockArea`。默认布局：
  - 左侧 dock：`NavigatorPanel`，宽 `pane.navigator.width`；
  - 中央：`ObjectPane`，由一个 `TabPanel` 承载对象选项卡和编辑器选项卡；
  - 右侧 dock：`InfoPanel`，宽 `pane.info.width`；
  - 底部 dock：默认为空、折叠。
- 分隔线宽 `pane.divider`，颜色为 `color.separator`。
- ⌘1 和 ⌘2 分别折叠或展开左侧和右侧 dock。
- 布局在退出时通过 `DockArea::dump` 写入 `state.json`，启动时通过 `DockArea::load` 恢复；如果版本不兼容或恢复失败，回退到默认布局。
- **偏差**：Navicat 的窗格位置是固定的，navidog 允许把面板拖到其他停靠位置。这是立项时确认的有意偏差。“窗口 > 重置布局”恢复默认布局。

## 5. 对象窗格（M1 部分）

- 第一个选项卡固定为“对象”选项卡，不能关闭。M1 中它显示：
  - 没有任何连接时，显示居中的空状态：图标，加上文字“点击工具栏中的‘连接’开始”；
  - 选中一个连接时，显示该连接已打开的数据库列表（列表视图），未打开时显示“未连接”状态；
  - 选中一个组时，列出组内的连接。
- 选项卡栏高 `tabbar.height`，下方是 1pt 分隔线。⌘} 和 ⌘{ 切换选项卡，⌘W 关闭当前选项卡（“对象”选项卡除外）。
- 右键选项卡出现“弹出为新窗口”。M1 中“对象”选项卡是唯一的选项卡且不可弹出，这个功能随 M2 的编辑器选项卡一起实现。

## 6. 导航窗格（M1 部分）

### 6.1 树结构

```
组 A
└── 连接 1（MySQL）
    ├── 数据库 a
    └── 数据库 b
连接 2（PostgreSQL）
└── 数据库 c
```

- 顶层直接是组和连接，没有“我的连接”根节点。按 `navigation_pane.html`，Navicat 只在登录 Navicat Cloud 之后才显示“我的连接”分区；navidog 在 M12 加入同步目录后，再以同样的方式分区显示。
- M1 的树到数据库为止；PostgreSQL 的模式和各类对象在 M2 加入。
- 行高 `navigator.row.height`，每级缩进 `navigator.row.indent`，图标 `navigator.row.icon`。
- 连接图标按数据库类型区分，未打开的连接图标为灰色。设置了连接颜色时，在行尾显示色块（行尾还是图标着色，待 AX 实测核对）。
- 选中状态：窗口激活时为 `color.selection` 背景加 `color.selection_text` 文字，失去焦点时为 `color.selection_inactive` 背景。
- 双击连接：未打开时打开连接，已打开时展开或折叠。双击数据库：打开该数据库（M1 中只是展开，没有子节点）。
- 实现：先用 `gpui-component` 的 `Tree`（基于 `uniform_list` 虚拟化）。M1 只需要单选，多选和拖放放到 M2 技术验证。连接组之间的拖放移动在 M1 中改用右键菜单“移动到组”实现（**临时偏差**，M2 补齐拖放）。

### 6.2 筛选栏

- 默认在窗格底部，“查看 > 导航窗格 > 在顶部显示筛选”可以移到顶部。高 `navigator.filter.height`，左右留 `navigator.filter.inset_x`。
- 搜索框高 `navigator.filter.search_height`，输入时实时筛选（不区分大小写，匹配名称），匹配项的上级自动展开。
- 三个快速筛选图标（连接类型、活动对象、标星）M1 显示为禁用，M2 实现。

### 6.3 右键菜单（`NativeMenu`）

| 节点 | 菜单项（M1） |
| --- | --- |
| 空白处或“我的连接” | 新建连接 ▸（数据库类型列表）、新建组、刷新 |
| 组 | 新建连接 ▸、新建组、重命名、删除组 |
| 已关闭的连接 | 打开连接、编辑连接…、新建连接 ▸、复制连接、删除连接…、颜色 ▸、移动到组 ▸、刷新 |
| 已打开的连接 | 关闭连接、编辑连接…、新建数据库…（M4，禁用）、新建查询（M3，禁用）、命令列界面（M3，禁用）、颜色 ▸、刷新 |
| 数据库 | 打开数据库、关闭数据库、刷新 |

菜单项名称以 `MainMenu.strings` 和 `Localizable.strings` 中的术语为准，写进 `locales/`。

**临时偏差**：Navicat 在树中原地编辑组名，M1 的“新建组”和“重命名”用一个输入组名的小对话框代替，M2 改为原地编辑。

### 6.4 键盘操作

上下方向键移动选中项；左右方向键折叠或展开；回车相当于双击；Delete 删除连接或组（需要确认）；⌘R 刷新。

## 7. 信息窗格（M1 部分）

- 顶部标题栏高 `info.header.height`，右上角是最大化按钮（`info.header.button`），点击后最大化宽度，再点还原（F-INFO-010）。
- M1 只有“常规”页：
  - 选中连接时显示：连接名称、类型、主机、端口、用户名、服务器版本（已打开时）、会话数；
  - 选中组时显示：组名称、连接数量；
  - 什么都没选中时显示：“没有选择对象”。

## 8. 状态栏（F-APP-004）

- 高 `statusbar.height`，文字使用 `font.size.small`、`color.label_secondary`，左边距 `statusbar.text_inset_x`。
- 显示当前活动面板提供的状态文本。M1 中，对象选项卡显示“N 个项目”或“N 个项目（已选择 1 个）”，导航窗格获得焦点时显示所选连接的类型和主机。
- “查看 > 显示状态栏”切换显示，状态持久化。

## 9. 菜单栏（F-APP-003）

M1 实现以下菜单。各菜单的完整结构参考 `reference/tree/MainMenu.txt` 和 AX 导出的菜单栏；后续里程碑的菜单项在实现时加入（**临时偏差**：M1 不显示尚未实现的菜单项）。

| 菜单 | 菜单项 |
| --- | --- |
| navidog | 关于 navidog、偏好设置…（⌘,）、检查更新…、服务、隐藏 navidog（⌘H）、隐藏其他（⌥⌘H）、全部显示、退出 navidog（⌘Q） |
| 文件 | 新建 ▸ 连接 ▸（数据库类型）、新建组；导入连接…（M6，暂不显示）；关闭选项卡（⌘W）；关闭窗口（⇧⌘W） |
| 编辑 | 撤销、重做、剪切、拷贝、粘贴、删除、全选（系统标准，用于输入框） |
| 查看 | 导航窗格 ▸（显示导航窗格 ⌘1、隐藏连接组、在顶部显示筛选）；信息窗格 ▸（显示信息窗格 ⌘2）；显示状态栏；显示工具栏（⌥⌘T）；进入全屏（⌃⌘F） |
| 窗口 | 最小化（⌘M）、缩放、重置布局、显示主窗口、全部置于顶层 |
| 帮助 | navidog 帮助（打开项目主页）、反馈问题 |

所有菜单项都是 Action，菜单栏调用 `cx.set_menus` 之前必须先调用 `cx.bind_keys`，否则菜单里不会显示快捷键。

## 10. 偏好设置窗口（F-PREF-001、F-PREF-002、F-PREF-010）

- ⌘, 打开独立窗口（单例，640 × 480），左侧是分类列表，右侧是设置页。外观和语言各占一行（标签加横向选项，对应 Navicat 的弹出菜单）。主窗口等是小节标题，下面是左对齐的复选框，不再套用连接表单的标签列。记录页的“限制记录”和每页条数在同一行。
- M1 包含两个分类：
  - **常规**：外观（跟随系统、浅色、深色）、语言（跟随系统、简体中文、English）、启动时自动打开“自动连接”的连接；
  - **高级**：设置位置（只读显示配置目录，带“在 Finder 中显示”按钮）、主密码（设置、修改、清除）。
- 修改立即生效：切换外观时调用 `Theme::change`；切换语言时调用 `set_locale` 和 `cx.refresh_windows()`。设置保存在 `settings.json`。

## 11. 配置文件

所有文件都在 `~/Library/Application Support/navidog/` 下：

| 文件 | 内容 | 所属 |
| --- | --- | --- |
| `settings.json` | 偏好设置 | `navidog-core` |
| `state.json` | 窗口位置尺寸、Dock 布局、各窗格显示状态 | `navidog` |
| `connections.json` | 连接和连接组（密码字段加密），见 [11-connection.md](11-connection.md) | `navidog-core` |
| `plugins.json` | 插件授权（M5） | `navidog-plugin` |

所有 JSON 都带 `"version"` 字段。写入时先写到临时文件，再原子替换，避免崩溃时损坏配置。
