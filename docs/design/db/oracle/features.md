# Oracle 专属功能

| 编号 | 功能 | 摘要与验收要点 | 帮助页 |
| --- | --- | --- | --- |
| F-ORA-001 | 连接常规设置 | 连接类型（Basic、TNS），主机、端口、服务名或 SID，角色（Default、SYSDBA、SYSOPER）。 | con_gen_settings_oracle |
| F-ORA-002 | 模式 | 以模式为中心的导航；模式下的对象分类。 | oracle_schema |
| F-ORA-003 | 表设计器差异 | 存储参数、外部表属性、访问参数、检查与唯一约束。 | oracle_table |
| F-ORA-004 | 视图与实体化视图 | 视图、实体化视图（刷新方式、计划）。 | oracle_view, oracle_mview |
| F-ORA-005 | 过程、函数与包 | 过程、函数；包规范与包体编辑。 | oracle_function, oracle_package |
| F-ORA-006 | 其他对象 | 序列、同义词、类型、数据库链接、目录、Java 等。 | oracle_others |
| F-ORA-007 | 回收站 | 查看、还原、清除回收站中的对象。 | oracle_recycle_bin |
| F-ORA-008 | 维护 | 分析、验证结构、收集统计信息、重建索引。 | oracle_maintain |
| F-ORA-009 | 表空间 | 表空间常规、高级、存储设置。 | mysql_tablespace（同类页） |
| F-ORA-010 | 安全性 | 用户、角色设计器；维护用户（锁定、解锁、过期密码）。 | security_oracle_user, security_oracle_role, security_oracle_user_maintain |
| F-ORA-011 | PL/SQL 调试器 | 断点、单步、调用栈、变量；调试 Oracle 查询。 | debugger_oracle, query_debug |
| F-ORA-012 | 数据泵 | 数据泵导出与导入向导。 | oracle_data_pump, oracle_data_pump_export, oracle_data_pump_import |
| F-ORA-013 | 命令列界面差异 | SQL*Plus 风格命令。 | console |
