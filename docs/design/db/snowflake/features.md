# Snowflake 专属功能

| 编号 | 功能 | 摘要与验收要点 | 帮助页 |
| --- | --- | --- | --- |
| F-SNOW-001 | 连接常规设置 | 账户标识、验证方式、仓库、角色。 | con_gen_settings_snowflake |
| F-SNOW-002 | 数据库与模式 | 新建、编辑、克隆数据库与模式。 | snowflake_database |
| F-SNOW-003 | 表设计器差异 | 搜索优化、聚类键、唯一约束；动态表（目标延迟、查询）；混合表的外键和索引。 | snowflake_table |
| F-SNOW-004 | 视图与实体化视图 | 普通视图、安全视图、实体化视图。 | snowflake_view, snowflake_mview |
| F-SNOW-005 | 过程与函数 | 多语言（SQL、JavaScript、Python 等）过程与函数。 | snowflake_function |
| F-SNOW-006 | 其他对象 | 阶段、管道、流、任务、序列、文件格式等。 | snowflake_others |
| F-SNOW-007 | 维护 | 维护对象相关操作。 | snowflake_maintain |
| F-SNOW-008 | 安全性 | 用户、角色、数据库角色设计器。 | security_snowflake_user, security_snowflake_role, security_snowflake_db_role |
