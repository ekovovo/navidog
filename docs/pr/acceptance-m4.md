## 2026-10-19 按 Navicat 重新对齐

字段网格包含名称、类型、长度、小数点、不是 null、虚拟、键、注释，提供单元格输入、类型菜单和复选项。下方提供默认值、排序规则、字符集、自动递增、无符号及生成表达式/存储类型；按字段类型和方言显示。SQLite 自动递增会将单字段 INTEGER 主键转为列内定义，避免产生无效 AUTOINCREMENT。

索引、外键和检查使用独立列表及表单；本表字段、索引方法、删除/更新动作可通过菜单选择。复杂属性/未知定义原样保留在高级页并提示，不通过表单丢弃。SQL 预览、明确执行和失败保留草稿继续沿用。存在无效输入时禁止切换对象或生成旧草稿的预览，修正后恢复。

## 2026-10-19 外键引用对象级联选择

引用模式（MySQL 为数据库、PostgreSQL 为当前数据库内模式）、表和字段新增元数据菜单；SQLite 保持当前数据库范围。字段按点选顺序组合，支持移除选中字段；自引用读取当前草稿字段。更换模式/表清空下级输入，已有定义与刷新候选不会互相改写；输入不完整或字段数不匹配时阻止预览。保留手工输入，支持尚未创建的引用对象。

元数据通过 Sessions::run_rel 异步读取，独立于保存会话；候选加载中禁用菜单，错误和重试入口就地显示；请求代次防止过期成功或错误覆盖新选择。类型、唯一键、排序规则等完整兼容性由数据库执行检查，不宣称前端已完整验证。

## 2026-10-19 表选项与方言属性

选项页替换占位说明，改为按方言显示的表单：MySQL/MariaDB 23 项常用选项（引擎、字符集、排序规则、自增、行格式、统计信息、目录、表空间、压缩/加密、注释等）；PostgreSQL 拥有者、表空间、继承、填充因子、自动清理及 UNLOGGED；SQLite WITHOUT ROWID、STRICT。输入只改草稿，保存先预览。未知选项原样保留，不通过常用参数编辑静默删除；无法安全修改的参数明确拒绝。

MySQL ALTER 只提交变化选项，避免重放未改自增值；清空已有显式选项时不能假装恢复默认，必须填写明确替代值。PG 从 pg_class/pg_inherits 加载选项并纳入并发指纹，SET/RESET、继承、表空间、拥有者和日志模式均在保存事务内执行，拥有者最后修改。SQLite STRICT 通过事务重建；不兼容数据失败回滚。已有表切换 WITHOUT ROWID 会丢失隐式行号，明确拒绝；新表允许。

字段新增 ON UPDATE、ZEROFILL 和 PG identity 模式。无符号、零填充、字符集、排序规则按 SQL 语法插到类型之后，保留其他属性；零填充同时设置无符号。PG 已有 identity 仅支持 ALWAYS/BY DEFAULT 模式切换，序列选项原样保留，不猜测增加/删除 identity 的复杂迁移。断线恢复草稿按保存的连接驱动识别方言。

## 2026-10-20 PostgreSQL 表与字段注释

PG 注释从补充 SQL 列表迁为独立数据：表注释放在选项页，字段注释在网格单元格编辑。支持读取、修改、清空、复制字段时保留注释、按原字段身份跟随重命名；删除字段不生成指向已删除字段的注释语句。旧草稿的 COMMENT ON TABLE/COLUMN 安全迁移，重复、无法识别或指向其他对象的语句保留并阻止保存，不按索引删除处理。

变更计划只生成必要的 COMMENT ON TABLE/COLUMN，空值生成 IS NULL；注释放在结构和选项变更之后、拥有者转移之前，在同一事务保存。文本使用 E 字符串，名称使用方言标识符引用，支持中文、单引号、反斜杠、换行和 SQL 标点，拒绝 NUL。没有重写旧版并发指纹格式，旧注释快照归一化后仍可检查和保存。

验证：工作区全量 224 项测试通过；表设计领域 19 项（含 MySQL/MariaDB/PG 实库和 SQLite）通过；设计器全部 6 项通过。PG 实库覆盖注释新建/读取/修改/清空、特殊名字与字段重命名、关闭 standard_conforming_strings 后的转义、未改注释不重复提交、旧快照保存、字段/注释一起回滚和外部表/字段注释变化检查。通过故意失败的最后一步拥有者变更，验证此前注释和新增字段全部回滚。UI 测试使用真实键盘和网格点击，验证旧草稿、注释输入、SQL 预览、恢复与复制。全量 clippy、fmt、裸值和 diff 检查通过；依赖审计通过，已有间接依赖警告保留。
